Help

Buttons

Just chat
Ask anything, no folder needed. Anything saved goes in Documents/Jeeves Chats.
Folder label (top left)
Click it to work in a different folder, or go back to just chatting.
Settings
Choose the AI service and model, connect or remove keys, set the daily spending limit, and how Jeeves addresses you.
Allow / Always allow / Don't allow
Jeeves asks before changing anything. "Always allow" stops the questions for changes inside this folder.
Square button, or Esc
Stops what Jeeves is doing.

Things you can type

/undo
Puts the folder back to how it was before Jeeves's last change.
/ask
Ask before every change again, after "Always allow".
/clear
Start a fresh conversation.
/folder
Work in a different folder (the same as clicking the folder label).

Keys

Enter
Send. Shift + Enter starts a new line.
Y / A / N
Answer a question: yes, always allow, or no.
Copying
Select any text and press Cmd + C, or right-click and choose Copy.
